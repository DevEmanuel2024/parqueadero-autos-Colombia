# Parqueadero Autos Colombia - Iteración 1

Sistema para registrar la entrada y salida de vehículos. Hecho con Python, Flask y SQLite.

## Cómo ejecutarlo
    pip install -r requirements.txt
    python app.py
Luego abrir http://127.0.0.1:5000

## Usuarios de prueba
- operario / operario123
- admin / admin123

## Placas de prueba
- ABC123 y XYZ987 tienen mensualidad vigente
- VEN000 tiene la mensualidad vencida
